## 🛠 01. The Search Algorithm (Alibaba.sh)

Standard search queries often return "High-Ad-Spend" entities (Trading Companies). To reach the root directory of a true factory, use the following filter logic:

*   **Namespace:** Switch to the `Manufacturers` tab.
*   **Boolean Filter:** Set `Verified Manufacturer == TRUE`.
*   **Integrity Check:** Request a live `ssh` (video call) to the machine floor. If the "Manufacturer" cannot provide a low-latency view of the hardware within 24 hours, set `IsFactory = FALSE`.

## 🏗 02. Hardware Stack: The 18G Standard

In the knitwear world, **Gauge (G)** represents the resolution of the physical output. 

| Gauge | Resolution | Machine Requirements | Target Segment |
| :--- | :--- | :--- | :--- |
| **3G / 5G** | Low-res (Chunky) | Standard Auto-Knit | Mass Market |
| **7G / 12G** | Mid-res (Standard) | Standard Auto-Knit | Average Retail |
| **18G** | **High-res (Ultra-Fine)** | **Stoll / Shima Seiki** | **Luxury / High-End** |

**Engineering Insight:** 18G production requires high-CAPEX German/Japanese hardware and high-precision skilled operators. Traders rarely own these assets. If a facility can execute **18G production**, you have likely found a top-tier direct manufacturer.

## 📜 03. Security & Compliance Layer

For brands targeting the EU/UK markets, compliance is a critical dependency, not a feature. 

*   **SMETA / BSCI:** Think of these as your SSL certificates. They verify the integrity of the work environment.
*   **OEKO-TEX®:** Verifies the safety of the raw material (Zero Toxic Inputs).

At **JM Sweater**, we maintain these "Security Certificates" globally. Never deploy a collection with a factory that cannot provide a valid, third-party audit report under NDA.

## 🚀 04. Deployment Strategy: Low-MOQ Logic

Traditionally, factories required `MOQ = 500`. This is an outdated buffer for inefficient production scheduling. 

In 2026, we utilize **Lean Manufacturing** to support:
- **Minimum Order Quantity (MOQ):** 50 pieces per style.
- **Goal:** Allow brands to "Beta Test" designs in the market with minimal capital risk.
- **Scaling:** Rapidly transition from 50 to 5,000 units once "Product-Market Fit" is verified.
